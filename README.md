# NAMU Trouble Shooting Wiki

사이트: https://namumg.github.io/NAMU/

로그인 없이 열람하는 기술 지원 위키입니다. 기존 다크 그린 디자인을 유지하며 문서와 원본 이미지를 필요할 때 불러옵니다.

## 파일 구조

- `index.html`: 기본 화면
- `css/style.css`: 공통 디자인
- `js/`: 화면, 데이터 로더, Hash Router, 검색, 관련 문서 추천
- `data/index.json`: 브랜드·모델·문서 목록과 버전별 파일 경로
- `data/articles/`: Flow 문서 ID 기반 개별 원본 문서 JSON
- `data/search-index.*.json`: 별도 검색 색인
- `data/synonyms.json`: 수정 가능한 한영 동의어 사전
- `images/`: 해상도·품질을 변경하지 않은 원본 이미지
- `api-sync/`: 서버에서만 실행하는 Flow 변환 및 검증 코드

`#/article/문서ID` 주소로 문서에 직접 접근할 수 있습니다. `/NAMU/` 경로에서 동작하며 즐겨찾기와 최근 열람은 기존 브라우저 저장값을 유지합니다.

## 자동 동기화 및 복구

한국 시간 매시간 정시를 기본 실행 시각으로 설정했습니다. 별도 복구 작업이 매시 7·22·37·52분에 그 시간대의 성공 기록을 확인합니다. 실행이 없으면 요청하고, 실패한 작업은 최대 총 3회까지 재시도합니다. 이미 대기·실행 중이거나 그 시간대에 성공했으면 중복 실행하지 않습니다.

두 작업 모두 GitHub Actions에서 실행됩니다. PC나 유료 서버는 필요하지 않지만, GitHub 예약 시스템 자체가 지연되거나 장애가 나면 복구 작업도 지연될 수 있습니다. 정각 완료나 장애 중 즉시 복구를 보장하는 별도 서비스는 아닙니다.

원할 때는 Actions → **Flow API sync & publish** → **Run workflow**를 누릅니다. 복구 점검은 **Flow update recovery**에서 확인합니다. 자동화는 실제 원본 변화가 있을 때만 데이터·이미지를 저장하며 화면 코드와 디자인을 재생성하지 않습니다.

API 키는 Actions Secret `FLOW_API_KEY`에만 있습니다. 공개 코드와 HTML에는 포함하지 않습니다. Pages의 Source는 **GitHub Actions**를 유지하세요.

## 데이터 보호

원본 제목·본문·노드 순서·이미지·메타데이터를 유지합니다. 문서와 모델이 API에서 누락되면 자동 삭제하지 않고 갱신을 중단합니다. 문제 유형 등 없는 필드는 만들지 않습니다. 기존에 숨겨져 있던 미분류/그룹 미지정은 데이터에는 남기고 기존 화면 표시 정책을 유지합니다.

검색은 제목·본문·브랜드·모델·실제 태그와 존재하는 추가 필드를 사용합니다. 추천은 동일 모델과 공통 태그만 사용하며 원문을 재작성하지 않습니다.
