# NAMU Trouble Shooting Wiki

로그인 없이 열람하는 기술 지원 위키입니다. 이미지와 회사 로고가 index.html에 포함되어 있습니다.

## GitHub Pages에 게시

1. GitHub 저장소의 최상위에 이 폴더 안의 `index.html`, `.nojekyll`, `README.md`를 올립니다. ZIP 파일 자체를 올리지 마세요.
2. 저장소 Settings → Pages를 엽니다.
3. Build and deployment에서 Source를 `Deploy from a branch`로 선택합니다.
4. 업로드한 브랜치(보통 main)와 `/(root)`를 선택하고 Save를 누릅니다.
5. 배포 완료 후 Pages에 표시된 주소로 접속합니다.

## 포함 기능

- 브랜드 → 모델 → 문제별 목차와 전체 목차 접기
- 제목·본문 검색, 긴 제목 말줄임
- 분류별 글씨 구분과 압축된 목록 간격
- 본문 내 원본 이미지 순서, 표와 문단 구조
- 태그 박스, NAMU 로고, 모바일 화면 대응
- 이미지 확대, Flow 원문 링크

## 데이터와 갱신

이 패키지는 마지막 수집 자료 18개와 이미지 41개를 저장한 정적 배포본입니다. 웹 방문자는 Flow 로그인이 필요하지 않습니다. Flow 원문 링크를 여는 경우에는 Flow 로그인이 필요할 수 있습니다.

**Flow 자동 갱신은 아직 연결되지 않았습니다.** GitHub에 업로드하는 것만으로 자동 갱신되지는 않습니다. 현재는 새 배포본의 index.html로 교체해야 자료가 갱신됩니다. 합의한 매시간 자동 갱신을 활성화하려면 별도로 GitHub 저장소, 서버용 Flow 인증 및 원본 이미지 배치 수집 경로를 설정해야 합니다.

메모 작성·저장 기능은 포함하지 않습니다. HTML에는 Flow 로그인 인증 키를 넣지 않았습니다. 배포된 문서·이미지는 공개 열람 대상입니다.
목록 업데이트: 5개 브랜드 및 그룹 미지정, 17개 모델, 25개 문제 항목. 신규 7개 문서는 제목과 Flow 원문 링크만 반영되었으며 본문은 가져오기 대기 상태로 표시합니다.
